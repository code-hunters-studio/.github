## 🧩 How we work

1. **📋 Plan** — requirements, decisions, and board-ready Stories  
2. **🎨 Prototype** — production-quality UI for the actor in focus  
3. **⚙️ Implement** — Frontend + Backend in dedicated private repos  
4. **🔁 Repeat** — next actor, same bar (no “MVP stub” delivery)
